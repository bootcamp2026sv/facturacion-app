---------------------------------------------

[ ] Definir VITE_API_URL antes de construir el frontend.

    Si frontend y backend se sirven bajo el mismo dominio mediante un proxy
    inverso, puede permanecer vacío y el frontend llamará a /api/v1.

    Si el backend utiliza otro dominio, asignar una URL HTTPS, por ejemplo:
    VITE_API_URL=https://api.su-dominio.com
